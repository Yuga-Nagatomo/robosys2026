# calorieコマンド
![test](https://github.com/Yuga-Nagatomo/robosys2026/actions/workflows/test.yml/badge.svg)

標準入力から料理名を受け取り、1人前あたりの推定カロリーを表示するコマンドです。

料理名の一部を入力すると、その文字列を含む登録済みの料理を検索できます。

## 使用方法

料理名を標準入力から入力します。

echo "ラーメン" | ./calorie

実行結果：

醤油ラーメン,470
味噌ラーメン,550
豚骨ラーメン,600
塩ラーメン,450

## 機能

料理名の部分一致検索

登録されている料理の推定カロリーを表示

1人前あたりのカロリーを表示

該当する料理がない場合はエラーを表示

空の入力の場合はエラーを表示

出力形式は「料理名,カロリー」です。カロリーは目安であり、料理の材料や量、調理方法によって異なります。
